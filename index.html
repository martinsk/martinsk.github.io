mskql

in-memory SQL

An in-memory analytics database that speaks the PostgreSQL wire protocol.

Analytical queries return in single-digit milliseconds — ~97K queries/second versus PostgreSQL's 508 on concurrent load, and 20× faster on aggregates. Beats DuckDB on aggregates, joins, CTEs, and writes. Connect with psql, pgAdmin, or any PostgreSQL driver on port 5433.

Bit-identical to PostgreSQL across 1,514 adversarial test cases. Query Parquet files directly with CREATE FOREIGN TABLE — no ETL. Native VECTOR(n) column type. Compiles to WebAssembly and runs entirely in the browser.

μ

array language

A minimal array language in the tradition of APL and K — ~1,000 lines of C, no dynamic memory allocation.

Expressions evaluate right-to-left using single-character verbs and higher-order adverbs (fold /, scan \). Element-wise operations, lambdas, and functional composition work out of the box.

Ships with built-in statistics, financial functions (Black-Scholes, Markowitz portfolio optimization, volatility-smile calibration), CSV parsing, and SVG/canvas plotting. Compiles to WebAssembly — runs entirely in the browser.

FreshQL

web platform · 2024

An in-memory key-value store with an HTTP templating engine built in — 10× the speed of Redis.

Templates bind directly to URL parameters and live database values; store an HTML template at a path and it serves instantly — no separate web layer, no JS framework. Written in C; its storage engine is the direct predecessor of mskql.
